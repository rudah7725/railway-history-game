# 철도는 누구에게 진보였을까?

**[▶ 게임 바로 실행하기](https://rudah7725.github.io/railway-history-game/)**

19세기 영국의 철도 확장을 건설 노동자와 기관사의 자리에서 탐색하는 한국어 2D 역사 체험 웹게임입니다. 설치 없이 PC·모바일 브라우저에서 플레이할 수 있습니다.

> 역사 자료 조사 전의 가상 시나리오를 포함한 시연용 초안입니다. 인물·대사·현장·선택 결과는 창작이며, 실제 사료의 인용이나 검증된 역사적 인과관계가 아닙니다.

## 무엇을 할 수 있나요?

- 공사 현장의 작업장·도구·숙소를 자유롭게 살펴보고 감독·동료와 대화합니다.
- 터널 굴착·제방 운반·석공 보조 중 한 곳에서 일합니다.
- 작업 중 드러난 문제에 대응하고, 완공 이후 다음 생계를 선택합니다.
- 인물의 이동과 작업, 현장 보강, 완성된 철길과 열차를 볼 수 있습니다.
- 처음과 마지막의 상태, 선택한 경로와 기회·부담을 결과에서 비교합니다.

일곱 역할 중 **철도 건설 노동자와 기관차 기관사**를 각각 세 장면으로 플레이할 수 있습니다. 다른 다섯 역할은 준비 중입니다.

기관사는 출발 준비 → 안개 속 운행 판단 → 도착 후 보고·휴식·추가 배치를 경험합니다. 기관차·노선·화부·책임자를 자유롭게 살펴보고, 운전석에서 행동을 고릅니다. 보고에는 마지막 장면의 화부 대화가, 추가 배치에는 책임자 대화와 피로 조건이 적용됩니다. 이는 가상의 체험 분기이며 실제 운전 규정이 아닙니다.

## 조작 방법

1. **시작하기 → 철도 건설 노동자**를 선택합니다.
2. 번호가 붙은 장소를 눌러 관찰합니다. 사람을 선택하면 **말 걸기**로 대화합니다.
3. 첫 장면은 작업장에서, 둘째 장면은 감독·도구·출입길에서 행동을 선택합니다.
4. 셋째 장면은 사람들에게 소개를 받거나 출입길에서 다음 생계를 결정합니다. 선택할 수 없는 행동에는 이유가 표시됩니다.
5. **어디로 갈까요?** 안내 버튼으로 행동할 장소에 바로 갈 수 있습니다. 관찰 수첩에는 실제로 읽은 설명과 대사가 남습니다.
6. 엔딩에서 생각을 적고 **체험 기록 내려받기**로 선택 경로·관찰·대화를 텍스트 파일에 보관할 수 있습니다. 내용은 서버로 전송되지 않습니다.
7. **다시 시작하기**로 다른 경로를 체험할 수 있습니다.

탐색만으로 피로가 증가하거나 시간이 흐르지 않습니다. **동작 줄이기**와 **애니메이션 건너뛰기**를 지원합니다. 플레이 기록은 브라우저 메모리에만 있으며 새로고침하면 초기화됩니다.

## 검토받고 싶은 점

- 노동자의 기회와 부담이 선택 과정에서 충분히 드러나는가?
- 앞선 관찰·대화·행동과 이후 상황의 관계가 납득되는가?
- 역사적 맥락과 자료를 보완하려면 어떤 사료·연구 질문을 우선해야 하는가?

## 자료와 한계

각 장면의 `researchNotes`에는 조사 질문을, `sources`에는 실제로 확인한 자료를 기록하도록 구성했습니다. 현재 출처 배열은 비어 있습니다. 게임 안의 **자료 안내**에서도 이 한계를 확인할 수 있습니다. 확인되지 않은 임금이나 사고 확률을 실제 수치처럼 제시하지 않습니다.

## 로컬 실행

Python 3이 있다면 추가 패키지 없이 실행할 수 있습니다.

```powershell
py -m http.server 8765 --bind 127.0.0.1
```

프로젝트 폴더에서 실행한 뒤 `http://127.0.0.1:8765/`에 접속합니다. Windows에서는 `start-server.bat`을 실행해도 됩니다. 종료는 터미널에서 `Ctrl+C`입니다.

## 구성과 개발 검증

- `data/roles.js`: 일곱 역할과 시작 화면 문구
- `data/scenarios/worker.js`: 장면·분기·관찰·대사·조사 메모
- `js/worker-model.js`: 선택과 상태 전이
- `js/worker-record.js`: 관찰·대화 기록과 텍스트 내보내기
- `js/worker-game.js`: 자체 SVG 장면과 상호작용
- `data/scenarios/driver.js`: 기관사 시나리오와 조사 질문
- `js/driver-model.js`, `js/driver-game.js`: 기관사 상태와 SVG 장면
- `js/app.js`: 시작·역할 선택 화면 연결
- `css/style.css`: 화면·애니메이션·좁은 화면 대응

이미 설치된 Node.js로 개발 검증을 실행할 수 있습니다. 게임 플레이에 Node.js는 필요하지 않습니다.

```powershell
node --test tests/*.test.cjs
```

자동 테스트 13개는 기관사 24개 경로와 역할별 조건을 검사하고, 기록 중복 방지·내용 내보내기와 함께 가능한 37개 선택 조합, 중복 선택 방어, 관찰의 무해성, 소개 조건, 재시작 초기화를 확인합니다. 실제 브라우저에서는 서로 다른 두 경로의 완주와 PC·390px 화면을 확인했습니다. 모든 브라우저·실기기를 검증한 것은 아닙니다.
